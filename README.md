# 他TA星球 · 2026 音乐年终报告

可直接运行的移动端插画 H5 Demo，包含 第1页 Loading、第2页授权主页面、第3页「星球年历」、第4页「月度听歌」。视频仅为第2页到第3页之间的转场，不单独计页。

## 预览与发布

- GitHub Pages：https://nightbeckon.github.io/ta-planet-music-2026/
- 本地预览：在此目录执行 `python3 -m http.server 4180`，打开 http://127.0.0.1:4180/ 。
- 纯静态 HTML/CSS/JavaScript，无依赖安装、无后端和构建步骤。
- Pages 发布来源：main 分支，根目录。保留 `.nojekyll`，所有资源均使用相对路径，适配仓库子路径。

## 功能

- Loading 完成到 100% 后切入主页面。
- 授权默认未勾选，说明可独立阅读。
- 主页面与视频使用真实首帧及相同裁切、调色。
- 云层漂移、星光呼吸、星轨和流星，支持系统减少动态效果。
- 《星光》背景音乐支持播放、暂停、继续和循环，图标同步真实播放状态。进入页面尝试自动播放；浏览器拦截有声自动播放时，首次点击页面后接续，手动关闭后保持关闭。
- 音乐跨页面持续，视频保持静音。后台暂停，前台按用户原有选择续播。
- 弱网与媒体失败提示、跳过和重播。报告数字为示例，不读取或上传个人账号数据。

## 调试参数


- `?loading=50`：将 Loading 进度固定在指定百分比，便于检查画面。
- `?error`：模拟插画加载失败，检查重试流程。
- `?slow`：资源就绪后再延迟 8.5 秒，检查弱网提示。

## 文件

- `index.html`：页面及共享控件。
- `app.js`：流程、授权、进度和音乐状态。
- `journey-video.js` / `journey-video.css`：视频首帧及转场。
- `ambient.js` / `ambient.css`：环境动效。
- `calendar.js` / `calendar.css`：第 3 幕「星球年历」，单屏逐日点亮、连续登录高亮与上滑入口（示例数据）。
- `welcome-grade.css`：已确认的主页面调色。
- `assets/`：本项目使用的插画、文字切图（WebP）、视频及音乐。

## 发布注意

- 每次发布请同步修改 `index.html` 中所有 `?v=` 版本号，避免 CDN / 微信缓存新旧文件混用。
- 新增切图请导出为 WebP（质量约 90），宽度不超过 3 倍屏实际显示尺寸。

## 第3幕单屏调整

移除年历大标题、日期回看与底部图例/附注/操作区；12个月自适应放入一屏。底部支持上滑或点击进入下一页的入口，第3页上滑或点击底部提示进入第4页。

页面顺序：Loading（1）→ 主页面（2）→ 视频转场 → 日历（3）→ 月度听歌（4）。已移除中间的报告首幕示意页。

## 第4页月度听歌

- 接入上传的 wave-scene 模块与6张 WebP 素材，保持2026年份、统一页头与同一音乐开关。
- 无新增外部字体依赖；海浪需要 WebGL2，不支持时保留天空背景、文本与数据。减少动态效果时显示静态完整数据。
- 演示中的歌手头像为空，因此沿用模块的姓名首字头像。
- 第4页底部上滑入口保留，第5页尚未提供，触发后显示准备中提示。

## 统一正式入口

所有体验入口（包括旧的 ?scene=calendar / ?scene=wave 链接）均从 Loading 开始，完成后进入主页面；授权开启后播放视频，落到日历；日历上滑后进入月度听歌。不再提供跳页预览参数。
